## 1. KAMIS 가격 (핵심 타깃)

**호출**: `http://www.kamis.or.kr/service/price/xml.do?action=...` + `p_cert_key`, `p_cert_id`

### 1-1. 일별 부류별 가격 `action=dailyPriceByCategoryList` ← **과거 데이터 수집용**
- 날짜 1개 × 부류 1개 × 소매/도매 1개 = 호출 1회. **과거 날짜를 넣을 수 있다(1998년까지 확인)**.
- 파라미터: `p_regday`(날짜), `p_item_category_code`(100 식량 · 200 채소 · 300 특용 · 400 과일 · 500 축산 · 600 수산), `p_product_cls_code`(01 소매 · 02 도매), `p_country_code`(지역, 빈값=전국평균)

| 컬럼 | 의미 | 예 |
|---|---|---|
| item_name / item_code | 품목 | 배추 / 211 |
| kind_name / kind_code | 품종(+단위) | 여름(고랭지)(1포기) / 02 |
| rank / rank_code | 등급 | 상품 / 04 |
| unit | 단위 | 1포기, 1kg, 100g, 1손 |
| dpr1 ~ dpr7 | 당일, 1일전, 1주전, 2주전, 1개월전, 1년전, **평년** 가격 | "5,890" (쉼표 포함 문자열) |

- 2026-09-22 기준 소매 품목 수: 채소 51, 수산 46, 축산 29 등.
  - 수산: 고등어, 갈치, 조기, 명태, 물오징어, 새우, 전복, 꽃게, 바지락, 홍합 등 24개 품목
  - 축산: 소(부위·등급별), 돼지, 닭, 계란, 수입 소·돼지, 우유
- `dpr7`(평년 가격)은 보고서 6장 "과거 동일 시기 대비" 기준으로 바로 쓸 수 있다.

### 1-2. 기간별 품목 가격 `action=periodProductList`
- **주의**: 과거 날짜를 넣어도 서버가 **최근 1년으로 바꿔서** 응답한다(2000~2025년 요청 모두 2025-09-30~2026-09-30로 반환). → 최근 1년 갱신용으로만 쓸 수 있다.
- 컬럼: `itemname, kindname, countyname(지역/평균), marketname, yyyy, regday(MM/DD), price`

### 1-3. 주의사항
- **품종 코드가 계절에 따라 바뀐다.** 배추는 봄(01), 여름 고랭지(02), 가을, 월동으로 나뉘고, 조회 날짜에 해당하지 않는 품종은 데이터가 없다(`"001"`). 하나의 "배추" 시계열로 이어 붙이는 규칙이 필요하다.
- **단위가 품목마다 다르다**(1포기, 10kg 그물망 3포기, 1손, 100g). 대체재 비교에는 원/100g 등으로 바꾸는 단위 환산표가 필요하다.
- 가격이 `"5,890"`, `"-"` 같은 문자열로 온다. 파싱이 필요하다.

## 2. MAFRA 농수축산물 도매가격

**호출**: `http://211.237.50.150:7080/openapi/{KEY}/json/{MAFRA_GRID_WHOLESALE_PRICE}/{시작}/{끝}?EXAMIN_DE=YYYYMMDD` (**EXAMIN_DE 필수**)
- 하루 약 700~740행. 2018-01-02, 2020, 2023, 2025, 2026-09-22 모두 확인했다. 명절 휴장일은 0행이다.

| 컬럼 | 의미 |
|---|---|
| EXAMIN_DE | 조사일 |
| FRMPRD_CATGORY_CD / _NM | 부류 (100 식량작물 ~ 600 수산, KAMIS와 같은 체계) |
| PRDLST_CD / _NM | 품목 (녹두, 미나리 …) |
| SPCIES_CD / _NM | 품종/산지 |
| GRAD_CD / _NM | 등급 (상품/중품) |
| EXAMIN_UNIT | 거래 단위 (20kg, 40kg) |
| AREA_CD / _NM | 지역 |
| MRKT_CD / _NM | 도매시장 |
| AMT | 가격(원) |

- **거래량(반입량) 컬럼이 없다** → 7장 "부족한 데이터"를 참고.

## 3. 축산물품질평가원 (data.go.kr 키)

**호출**: `http://data.ekape.or.kr/openapi-data/service/user/...?serviceKey=` (XML)
유통정보 10개 + 등급판정 24개, 모두 34개 오퍼레이션이 있다. 중요한 것만 정리했다.

| 오퍼레이션 | 경로 | 주요 컬럼 | 확인 |
|---|---|---|---|
| 일자별 소비자가격 | `grade/consumerPriceDaily` (standYmd, judgeKind, itemCd) | 부위(itemNm), 등급(grdNm), 평균·최대·최소가, **17개 시도별 가격**, 단위 원/100g | 소 안심 ✅ / 돼지 itemCd 확인 필요 |
| 월별 소비자가격 | `grade/consumerPriceMonth` | 가격, **평년가격** | 명세만 확인 |
| 축산물 재고동향 | `grade/LPStock` (standYyyy, standMm, judgeKind) | 부위별 재고량, 재고 합계 | 파라미터 보완 필요 |
| 소 경락가격 | `grade/auct/cattle` | 등급별 × 도매시장별 **경락단가(Amt)·두수(Cnt)** | ✅ 11행/일 |
| 돼지 등급별 경락가 | `grade/auct/pigGrade` | 등급별 × 시장별 단가·두수 | ✅ |
| 돈육 대표가격 | `grade/auct/pigRepresentativePrice` | 집계일, 박피/탕박 구분, 지수 | ✅ |

- 경락 `Cnt`(두수)를 **도축량의 대용 지표**로 쓸 수 있다.
- 축종코드: 4301 소, 4304 돼지 (나머지는 코드표로 확인해야 한다)

## 5. 기상청 ASOS (data.go.kr 키)

**일자료**: `apis.data.go.kr/1360000/AsosDalyInfoService/getWthrDataList` (dataCd=ASOS, dateCd=DAY, startDt, endDt, stnIds)
**시간자료**: `.../AsosHourlyInfoService/getWthrDataList` (dateCd=HR). 쓸 일은 거의 없다.

일자료 컬럼 62개 중 쓸 만한 것:

| 컬럼 | 의미 |
|---|---|
| tm, stnId, stnNm | 날짜, 지점 |
| avgTa / minTa / maxTa | 평균·최저·최고 기온 → 폭염·한파 |
| sumRn, hr1MaxRn | 일강수량, 1시간 최다 강수 → 호우 |
| sumSsHr, sumGsr | 일조시간, 일사량 |
| avgRhm | 평균 습도 |
| maxInsWs, maxWs | 최대 순간·최대 풍속 → 태풍 대용 |
| ddMes | 최심 적설 |
| avgTs, avgCm10Te 등 | 지면·지중 온도 |
| iscs | 일기현상 텍스트 |

- 지점은 주산지(예: 대관령=고랭지배추, 무안=양파)를 골라야 한다. 품목-주산지 매핑이 필요하다.

### 수집할 때 알아둘 점
- **KAMIS 과거 데이터**: 날짜 × 부류(6) × 소매/도매(2) = 하루 12회 호출. 10년이면 약 44,000회라서, 하루 호출 한도를 확인하고 여러 날에 나눠 받아야 할 수 있다.
