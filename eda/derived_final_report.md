## 1. 요약
- **R² 0.6 목표: 미달.** 최종 R² 농산물 0.459, 축산물 0.195, 수산물 0.243 (출발점 0.419 / 0.146 / 0.162)
- **왜 미달인가 (천장 진단):** 검증 행의 90% 이상인 지역 행에는 지역별 개별 변동이 큼. 품목·날짜 공통 움직임을 **완벽히** 맞혀도 지역 행 R² 상한이 농 0.71 / 축 0.47 / 수 0.27 → 축·수는 원리적으로 0.6 불가, 농만 여지 있음
- **대체 지표 (사전 기준: 표시 비율 ≥30%에서 방향 정확도 ≥0.80):** 회귀 + 방향 분류가 같은 방향일 때만 "오를 것/내릴 것"을 표시하면
  - 농산물 표시 59% · 정확도 **0.821** ✅ / 축산물 34% · **0.813** ✅ / 수산물 29.3% · **0.803** (정확도는 충족, 표시 비율 0.7%p 부족)
- **모델:** LightGBM이 가장 적합. 큰 모델·XGBoost·CatBoost 단독은 모두 LightGBM 기본보다 나빴고(기간 간 구조 변화로 과적합), 앙상블은 농산물에서만 이득

## 3. 최종 구성

| 분야 | 피처 | 학습 설정 | 모델 |
|---|---|---|---|
| 농산물 | 기본 + D4 도매(가락)-소매 괴리 이상치, D6 2주 강수 누적, D20 2주 일조 평년 대비, D21 2주 기온 평년 대비 | 그대로 | LightGBM 5시드 + XGBoost + CatBoost 평균 |
| 축산물 | 기본 | 학습 y 1~99% 자르기, 단조 제약(방향 점검 '일치' 15개) | LightGBM 5시드 평균 |
| 수산물 | 기본, 단 지수류(소비자물가·환율·유가·수입물가) 수준값 → 4주·13주 변화율로 교체 | Huber 손실(δ 0.05), 단조 제약 | LightGBM 5시드 평균 |
| 공통 (앱 방향 표시) | 같은 피처 | 방향 3분류 LightGBM (3시드) | 회귀 \|ŷ\|≥2% 이고 분류가 같은 방향(P≥0.4)일 때만 표시 |

채택된 파생변수의 사전 가설: D4 도매가가 평소보다 소매 대비 높으면 소매가 뒤따름(+) / D6 호우 누적 → 작황 피해(+) / D20 일조 부족 → 시설 과채 출하 감소(−) / D21 기온 이상(조건부). D20·D21은 겨냥한 시설 과채류 R²가 0.458 → 0.481로 가장 크게 올라 가설과 일치

## 4-2. 2라운드 (사용자 요청: 변수 성격별 파생변수, 앙상블 가중치·스태킹, 추론 시간)
- **변수 성격별 파생변수:** 지수류 → 변화율, 물량류 → 전년 동기 대비, 해양·양식장 → 평년 대비를 그룹 단위로 시험. **수산물에서 지수 수준값을 변화율로 교체하자 R² 0.224 → 0.242, 방향 0.703 → 0.714** (시드 3개 모두 개선, 사전 가설: 수준값은 시간 표시). 농·축은 효과 없음
- **앙상블 가중치(B)·스태킹(C):** 2022년으로 정한 가중치·메타 모델이 2023~24로 옮겨지지 않아 단순 평균보다 나쁨 → 기각. 단순 평균이 가장 안정
- **추론 시간:** 하루치 예측은 앙상블 전체로도 1초 미만(농산물 하루 약 2,500행). 재학습은 농산물 앙상블 약 14분(CatBoost 9분) → 하루 1회 예측 · 주/월 재학습이면 서비스 적용에 문제없음

## 5. 앱 적용 제안
- **예측값 그대로가 아니라 방향 안내로:** "향후 4주 오를 것 / 내릴 것 / 보합"을 회귀·분류가 합의할 때만 표시 (농 59%, 축 34%, 수 31% 행에서 표시, 정확도 0.80~0.82)
- **품목별 신뢰도 표시:** `eda/tables/app_item_reliability.csv` — 시금치(R² 0.71)·상추(0.67)·파프리카(0.61)·얼갈이(0.60)·참외(0.59) 등 엽채·과채는 품목 단위로 R² 0.6 수준. 김(−0.29, 수출 호황 국면)·복숭아·절임배추 등은 예측 표시 제외 권장
- 저장 품목(콩·팥·참깨·건고추 등)은 변화가 작아 대부분 '보합' 표시

## 6. 남은 과제
- 수산물 방향 안내: 정확도 0.803으로 충족했으나 표시 비율 29.3%로 0.7%p 부족. 임계값을 맞추면 검증셋 과적합이 되므로 조정하지 않음 → 2025~ 테스트셋 1회 평가에서 최종 판정
- 지역 개별 변동을 줄여 학습(M18)하면 오히려 나빠짐 → 지역 변동 중 예측 가능한 몫(프리미엄 되돌림)은 이미 쓰는 중
- 한우·닭은 일별 산지(도매) 가격이 없어 선행 신호 부재 (한우 주간 경락가는 수집했으나 효과 없음)
- `scripts/build_features.py`에 최종 파생변수·학습 설정을 옮기고 2025~ 테스트셋으로 1회 최종 평가
